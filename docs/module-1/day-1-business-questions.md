# Module 1 Day 1: Business Question to Data Question

## Exercise purpose

This exercise helped me turn a broad business question into a question that can be answered with data.

## My questions

### Question 1
Business question:  
Which menu items are most popular with customers?

Data question:
How many times was each menu item ordered during the selected month?

Fields or data needed:  
Menu item name or ID, order date, and quantity ordered.

Can the current dataset answer it?
Yes / Partly / No, followed by your reason.

Partly—it can answer this if it includes item names, dates, and quantities for each order.

### Question 2
Repeat the same structure for another question.

Business question:  
Which days are busiest for the restaurant?

Data question:
How many orders were placed on each day during the selected month?

Fields or data needed:  
Order date and order ID.

Can the current dataset answer it?
Partly—it needs order dates and a unique order ID so the orders can be counted by day.

## What I learned

Write 2 - 4 sentences about the difference between a business question and a data question.

A business question describes a decision or concern in everyday terms, while a data question turns it into something specific that can be measured. A clear data question helps identify which fields are needed and whether the available dataset can answer it.
