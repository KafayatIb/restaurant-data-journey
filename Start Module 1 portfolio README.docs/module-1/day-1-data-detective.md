# Module 1 Day 1: Data Detective

## Exercise purpose

The purpose of this exercise was to classify different examples of data by data type, structure and likely format or medium.

## My completed classification


|---|---|---|---|---|
| Data example | Classification | Structure | Likely format / medium |
|---|---|---|---|
| Restaurant transaction table | Identifier | Unstructured | CSV |
| Customer review written online | Qualitative | Unstructured | Plain text notes |
| JSON order response from a delivery application | Qualitative | Semi-structured | Labels and keys, Nested |
| Menu price | Quantitative | Structured | Number or currency field in a database or spreadsheet |
| Photograph of a meal | Qualitative | Unstructured | Image file, such as JPEG or PNG|
| Restaurant branch name | Qualitative | Structured | Text field in a database or spreadsheet |
| Number of orders each day | Quantitative | Structured | Date and integer columns in a table or spreadsheet |
| Spreadsheet containing employee shifts | Identifier, Quantitative, Qualitative | Structured | Spreadsheet, such as XLSX or CSV |
| Audio recording of a customer-support call | Qualitative | Unstructured | Audio file, such as MP3 or WAV |
| Payment method | Qualitative | Structured | Category field, such as “cash” or “card,” in a database or spreadsheet |
## What I learned:
Data can be classified in more than one way: by whether it is qualitative or quantitative, and by how it is structured. Structured data is arranged in a consistent format, while unstructured data—such as photos, audio, and free-text reviews—does not follow a fixed table layout. The format or medium describes how the data is stored, such as in a CSV file, an image, or an audio recording.
