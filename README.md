### Day 1 Reflection

One thing I understand more clearly about data now is:  
Data can be classified by what it describes and how it is organised. For example, structured data fits into rows and columns, while reviews, photos, and recordings are unstructured.

One example of quantitative data and one example of qualitative data is: 
The number of orders placed each day is quantitative data. A customer’s written review is qualitative data.

One question I would like to answer using restaurant data is:
Which menu items are ordered most often?.

One concept I want to practise further is: 
Turning a broad business question into a specific data question.
